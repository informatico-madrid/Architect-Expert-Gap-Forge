### Key Discovery: "Inconsistencies" Are By Design

The "inconsistencies" discovered during research (DSPy English vs Stage 2 Spanish, orphaned YAMLs, dead code) are **NOT bugs in this spec**. They are intentionally scoped to Epic 1:

- **Epic 0 (this spec)**: Catalog + translate prompts → `.example.yaml` templates. No code changes.
- **Epic 1 (FR-008)**: Replace hardcoded Spanish in production code with DSPy Signatures. Connect externalized prompts to DSPy.

### Implications for This Spec

1. **Scope is correct as expanded (7 files)**: Even orphaned sources will eventually be consumed by DSPy in Epic 1
2. **Do NOT delete dead code**: `frontend_taxonomy_prompts.py`, orphaned calibration YAMLs — leave for Epic 1
3. **Note handoff to Epic 1**: Each `.example.yaml` should document which Epic 1 story it feeds
4. **Coexistence is by design (AC3)**: Stage 2 uses taxonomy YAMLs. DSPy will use `.example.yaml`. Different consumers.
