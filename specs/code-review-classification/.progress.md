## Learnings

- Bug #16 (exists() vs is_file()): CONFIRMED. Line 87 of `infrastructure/anchor_dataset/anchor_dataset_schema.py` uses `file_path.exists()` which returns True for both files and directories. Should use `is_file()` to only match regular files. `file_path.stat().st_size == 0` is also problematic when file_path is a directory.
- Bug #38 (os.chdir() side-effect): CONFIRMED. Line 243 of `infrastructure/rollback_check.py` calls `os.chdir(isolated_path)` which mutates global process working directory. Any concurrent code in the same process sees this change. Should use pathlib Path operations or context manager instead.
- Bug #75 (os.fsync() fd usage): In `specs/anchor-dataset/requirements.md` FR-009.5 references atomic write pattern (temp + rename + fsync) and FR-010.4 references "temp + rename + fsync". The spec mentions os.fsync() but the actual implementation files need to use proper file descriptor (int) not path string.
- File paths for task files: `anchor_dataset_schema.py` is at `infrastructure/anchor_dataset/anchor_dataset_schema.py` (not `infrastructure/anchor_dataset_schema.py`), `rollback_check.py` is at `infrastructure/rollback_check.py`
