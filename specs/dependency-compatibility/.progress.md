### Surface findings
- All four new deps compatible, zero direct conflicts
- torch does NOT come from DSPy (must add explicitly)
- dspy-ai is deprecated wrapper, use dspy directly
- numpy bug confirmed (imported in 2 files, missing from requirements)
- openai must move from dev to runtime

### Deep audit findings (what surface check missed)
- litellm 1.82.6 has 6 CVEs (2 Critical + 4 High); dspy pins `<=1.82.6` blocking patches
- tokenizers + tiktoken have NO Python 3.14 wheels — CI source build failure guaranteed without Rust
- datasets jumped from 2.21.0 to 4.8.4 — must pin `>=2.19,<3.0` to prevent 4.x API breakage
- langchain-core 0.3.84 is in langgraph 0.2.76's exclusion list — works by coincidence of pip resolver
- Release cadences too fast for `>=` ranges: litellm every 2.4 days, openai every 5-7 days, dspy every 1-3 months
- Total installed size: 595 MB without torch, 2.1 GB with torch CPU, 3.6 GB with torch full (NOT 3GB as previously summarized)
- 6 distinct CI/CD failure modes identified
- Strict version pinning (`==`) recommended over ranges for ML pipeline reproducibility
