## Key Implementation Details

1. **ExtractorAdapter Protocol** - Defined in `src/utils/extractors/base.py` with:
   - `parse_file(file_path: Path) -> ParseResult`
   - `extract_dependencies(file_path: Path) -> List[Dependency]`
   - `ParseError` exception with file_path, line, message
   - Policy options: abort, skip, fallback

2. **PythonAstAdapter** - Implementation preserving existing AST logic in `src/utils/extractors/python_ast_adapter.py`

3. **Factory** - Lazy-loading adapter factory in `src/utils/extractors/factory.py`
